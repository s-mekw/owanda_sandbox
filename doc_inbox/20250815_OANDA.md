# PythonでOANDA経由でFXチャート情報を取得する方法
以下は**PythonでOANDAのAPIからFXのチャート（ローソク足・価格ストリーム）を取得する実践ガイド**です。最小構成 → しっかり運用構成 → 発展（ストリーミング/大量データ）という順でまとめます。

## 1) まず押さえるポイント（超要約）

- **認証**：個人アクセストークンを**HTTPのBearerトークン**として送る。練習口座＝`api-fxpractice.oanda.com`、本番＝`api-fxtrade.oanda.com`
- **ローソク足API**：`GET /v3/instruments/{instrument}/candles`  
  例：`USD_JPY` の `M5` を `count=500` 取得、価格は **mid/bid/ask** のいずれか（`price=M|B|A`）
- **粒度**：`S5…M1…H1…D…W…M` と豊富（秒足〜月足）
- **リアルタイム価格**：`/v3/accounts/{accountID}/pricing/stream`（最大毎**250ms**で各銘柄あたり**4tick/秒**）

## 2) しっかり運用構成：公式ラッパー **oandapyV20** を使う

公式が提供するv20エンジン向けのPythonラッパー（有志メンテ）を使うと、エンドポイントを安全に叩けます。

```bash
pip install oandapyV20
```

```python
import os
import polars as pl
from oandapyV20 import API
import oandapyV20.endpoints.instruments as instruments

TOKEN = os.environ["OANDA_TOKEN"]
client = API(access_token=TOKEN, environment="practice")  # "trade" で本番

params = {"granularity": "M5", "count": 500, "price": "M"}
r = instruments.InstrumentsCandles(instrument="USD_JPY", params=params)
client.request(r)  # 実リクエスト

candles = r.response["candles"]  # レスポンスは r.response に格納
df = pl.DataFrame([{
    "time": c["time"],
    "complete": c["complete"],
    "volume": c["volume"],
    "open": float(c["mid"]["o"]),
    "high": float(c["mid"]["h"]),
    "low":  float(c["mid"]["l"]),
    "close":float(c["mid"]["c"]),
} for c in candles]).with_columns([
    pl.col("time").str.to_datetime().dt.replace_time_zone("UTC")
])
```

### 便利Tips

- **対応銘柄の一覧**：口座で取引可能な銘柄は `GET /v3/accounts/{accountID}/instruments` で取得（ラッパーなら `AccountInstruments`）
- **最新の価格**は `/pricing`、**ティックのストリーム**は `/pricing/stream`（後述）

## 4) よく使うパラメータの理解（ローソク足）

`GET /v3/instruments/{instrument}/candles` の主なクエリ：

- `granularity`：秒足〜月足（`S5,S10,S15,S30,M1,M5,...,H1,D,W,M`）
- `count` / `from` / `to`：本数または期間指定
- `price`：`M`=mid, `B`=bid, `A`=ask（返却フィールド名が `mid/bid/ask` に変わる）
- `includeFirst`：`from` で指定した時間に**かかっている最初の足を含めるか**。データの継ぎ足ポーリング時に便利
- `smooth`：**始値を前足終値でスムージング**するか否か（デフォルトはFalse）
- `dailyAlignment` / `alignmentTimezone` / `weeklyAlignment`：日足・週足の**区切り時刻/曜日/タイムゾーン**の整列を制御（タイムスタンプ自体は**UTCで返る**点に注意）

## 5) リアルタイム：価格ストリームを読む（ティック）

**板寄せではなく逐次価格**を受け取りたい場合は**ストリーミング**を使います。

```python
from oandapyV20 import API
import oandapyV20.endpoints.pricing as pricing
import json

client = API(access_token=TOKEN, environment="practice")

params = {"instruments": "USD_JPY,EUR_USD"}
r = pricing.PricingStream(accountID=os.environ["OANDA_ACCOUNT_ID"], params=params)

# ストリームはジェネレータで受け取れる
for msg in client.request(r):
    # msg は dict（type で分岐可能）
    t = msg.get("time")
    bids = msg.get("bids", [])
    asks = msg.get("asks", [])
    if bids and asks:
        print(t, "bid:", bids[0]["price"], "ask:", asks[0]["price"])
```

エンドポイントは `GET /v3/accounts/{accountID}/pricing/stream`。**各銘柄につき最大4tick/秒（=250ms間隔）**で配信されます。

## 6) 大量の過去データを取りたい（自動分割）

OANDAは一度に返せる本数に上限があります。長期間の取得は**期間を分割**して繰り返すか、`oandapyV20.contrib.factories.InstrumentsCandlesFactory` を使うと自動で**連続リクエスト**を回してくれます。

```python
from oandapyV20.contrib.factories import InstrumentsCandlesFactory
import oandapyV20.endpoints.instruments as instruments

params = {"granularity": "H1", "price": "M", "from": "2025-07-01T00:00:00Z", "to": "2025-08-01T00:00:00Z"}
for r in InstrumentsCandlesFactory(instrument="USD_JPY", params=params):
    client.request(r)
    for c in r.response["candles"]:
        pass  # ここで蓄積（polarsへconcatなど）
```

## 7) つまずきやすいポイント（実務のコツ）

1. **タイムゾーン**：APIは**UTC**で時刻を返します。日本時間にするなら `.dt.convert_time_zone("Asia/Tokyo")`。日足の区切りなどは `dailyAlignment`/`alignmentTimezone` で調整（ただし返却時刻はUTCのまま）
2. **未確定バー**：直近バーは `complete=False`。バックテスト/学習データに混ぜると「先読み」誤差が出るので除外を。（`complete` フラグは `/candles` 応答に含まれます）
3. **mid/bid/askの選択**：インジケータや約定コストの想定に応じて使い分け。スプレッド影響を含めたいなら `B`/`A`、汎用的分析は `M` が手軽
4. **レート制限/ポーリング**：ストリーミングは**4tick/秒/銘柄**の上限がある設計。高速スキャル用途での「取りこぼし」は仕様として理解しておく
5. **対応銘柄の違い**：規制区分により**取引可能銘柄は口座ごと**に異なるため、まず `AccountInstruments` で確認
6. **旧ライブラリとの混同**：`oandapy`（v1 API向け）は廃止済み。**`oandapyV20` を使う**

## 8) 次の一歩（可視化・保存・テスト）

- **可視化**：`mplfinance` でローソク足描画（移動平均や出来高を簡単に重ねられます）
- **保存**：`df.write_parquet()` や `write_csv()` で資産ごと・粒度ごとにディレクトリ保存
- **ユニットテスト**：`complete=True` のみで学習セットを作る、価格の連続性（`smooth`設定）を固定する、など**データ前処理の不変条件**をテスト化すると堅牢になります

## 付録：期間指定の例（from/to + includeFirst）

```python
params = {
    "granularity": "H1",
    "from": "2025-08-01T00:00:00Z",
    "to":   "2025-08-15T00:00:00Z",
    "price": "M",
    "includeFirst": False,  # 前回取得の終端重複を避ける
    "smooth": False,
    "dailyAlignment": 17,   # NY17時区切り（デフォルト）
    "alignmentTimezone": "America/New_York"
}
```

必要なら、あなたの**環境（WindowsかLinuxか、仮想環境の有無、保存先、欲しい通貨ペアと粒度）**を教えていただければ、**そのままコピペで動くスクリプト**（取得・保存・可視化・増分更新）をこちらで作ります。
